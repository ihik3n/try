# Κοστολόγηση ζαχαροπλαστείου · αρτοποιίας · gelato

Εφαρμογή στα ελληνικά για καθημερινή χρήση στο εργαστήριο, από κινητό και υπολογιστή, με κοινά δεδομένα.

**Ροή:** τιμολόγια αγοράς → αρχείο υλικών & τιμών → συνταγές → κοστολόγηση τελικών προϊόντων → προγραμματισμός παραγωγής.

## Τι κάνει

| Ενότητα | Λειτουργίες |
|---|---|
| **Τιμολόγια** | Φωτογραφία από το κινητό (και πολλές σελίδες) ή εικόνες/PDF πολλών σελίδων. Αυτόματη ανάγνωση με AI (προμηθευτής, αριθμός, ημερομηνία, κωδικοί, ποσότητες, συσκευασίες, τιμές, εκπτώσεις, καθαρή αξία, ΦΠΑ). Πίνακας ελέγχου με διόρθωση κάθε γραμμής πριν την ενημέρωση. Αβέβαιες τιμές σημειώνονται με κίτρινο, κενά πεδία δεν συμπληρώνονται αυθαίρετα. Αποθήκευση ως πρόχειρο, προειδοποίηση για διπλά, σύνδεση του αρχικού αρχείου με τις αγορές. |
| **Υλικά** | Πρώτες ύλες και συσκευασίες με κατηγορία, μάρκα, χαρακτηριστικά, μονάδα κοστολόγησης (kg / λίτρο / τεμάχιο), προμηθευτές, συσκευασίες αγοράς, ιστορικό τιμών, ενεργή τιμή και προέλευσή της. Αναζήτηση με ή χωρίς τόνους, φίλτρα, χειροκίνητη προσθήκη/διόρθωση. Αποθηκευμένες αντιστοιχίσεις περιγραφών τιμολογίου. |
| **Συνταγές** | Υλικά σε g, kg, ml, λίτρα ή τεμάχια· κόστος ανά υλικό, συνολικό κόστος, σύνολο υλικών, πραγματική απόδοση ή εκτιμώμενη φύρα, κόστος ανά kg / λίτρο / τεμάχιο. Επιμέρους συνταγές (μους, crumble, κρέμα, παντεσπάνι) χωρίς διπλομέτρηση και με αποτροπή κυκλικών συνδέσεων. Αντιγραφή, σημειώσεις παρασκευής, αναλογική κλιμάκωση και εκτύπωση. |
| **Προϊόντα** | Ποτηράκια, πάστες, τούρτες, μπισκότα, μερίδες gelato: συνταγές + πρόσθετες πρώτες ύλες/διακόσμηση + συσκευασίες. Αναλυτικό κόστος κάθε στοιχείου και ανά τεμάχιο. |
| **Παραγωγή** | «Θέλω 60 ποτηράκια» → ποσότητα κάθε επιμέρους συνταγής (και παρτίδες), συγκεντρωτικές πρώτες ύλες (κοινά υλικά σε μία γραμμή), συσκευασίες, συσκευασίες αγοράς, κόστος. Εκτύπωση, Excel, CSV, αποθήκευση πλάνων. |
| **Εργασία & έξοδα** | Προαιρετικά: χρόνος και ωριαίο κόστος, σταθερό ποσό ανά παρτίδα, ποσοστό σε σαφή βάση. Χωριστή εμφάνιση πρώτων υλών, συσκευασιών, εργασίας, λειτουργικών και συνόλου, με ένδειξη «δεν έχει καταχωριστεί». |
| **Ιστορικό** | Κάθε μεταβολή τιμής: υλικό, παλιά/νέα τιμή, μεταβολή € και %, επηρεαζόμενες συνταγές/προϊόντα με παλιό και νέο κόστος. Στιγμιότυπα κοστολογίων με ημερομηνία για σύγκριση με το σήμερα. |
| **Δεδομένα** | Μόνιμη αποθήκευση (SQLite), πρόσβαση με κωδικό, αυτόματα αντίγραφα ασφαλείας και επαναφορά, εξαγωγές Excel/CSV, πλήρες αντίγραφο (.zip) με όλα τα δεδομένα, τις συνδέσεις και τα παραστατικά. |

Εκτός της παρούσας έκδοσης: πλήρης διαχείριση αποθήκης, λογιστική, σύνδεση με ταμειακή, πιστωτικά τιμολόγια ως αρνητικές αγορές.

## Εγκατάσταση

### Α. Με Docker (συνιστάται για server/VPS)

```bash
git clone <αυτό το repository> kostologisi && cd kostologisi
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env      # προαιρετικό: αυτόματη ανάγνωση τιμολογίων
docker compose up -d --build
```

Η εφαρμογή ανοίγει στο `http://<διεύθυνση-server>:3000`. Τα δεδομένα μένουν στον φάκελο `./data` (βάση, παραστατικά, αντίγραφα ασφαλείας).

Για πρόσβαση από το διαδίκτυο βάλτε μπροστά HTTPS (π.χ. [Caddy](https://caddyserver.com/): `caddy reverse-proxy --from kostologisi.example.gr --to localhost:3000`) και ορίστε `COOKIE_SECURE=1`.

### Β. Σε υπολογιστή του καταστήματος (Windows / macOS / Linux)

Χρειάζεται [Node.js 22](https://nodejs.org/) ή νεότερο.

**Windows, ο απλούστερος τρόπος:** διπλό κλικ στο `start-windows.bat`. Την πρώτη φορά εγκαθιστά ό,τι χρειάζεται και μετά ανοίγει την εφαρμογή στον browser. Το παράθυρο πρέπει να μένει ανοιχτό όσο τη χρησιμοποιείτε. Αν τα Windows ρωτήσουν για το Τείχος προστασίας, επιτρέψτε την πρόσβαση στα «Ιδιωτικά δίκτυα», ώστε να ανοίγει και από το iPhone.

Με εντολές (στο PowerShell γράψτε `npm.cmd` αντί για `npm`, αλλιώς εμφανίζεται το σφάλμα «running scripts is disabled on this system»):

```bash
npm install
npm run build
npm start
```

Ανοίξτε `http://localhost:3000`. Από το κινητό, στο ίδιο Wi‑Fi: `http://<IP του υπολογιστή>:3000` (π.χ. `http://192.168.1.20:3000`).

Την πρώτη φορά η εφαρμογή ζητά να δημιουργήσετε όνομα χρήστη και κωδικό. Τον ίδιο λογαριασμό χρησιμοποιείτε από όλες τις συσκευές· από τις Ρυθμίσεις προσθέτετε κι άλλους χρήστες.

Για εγκατάσταση στο iPhone/iPad δείτε την επόμενη ενότητα.

## iPhone / iPad

Η εφαρμογή εγκαθίσταται στην αρχική οθόνη και ανοίγει σε πλήρη οθόνη σαν κανονική εφαρμογή, χωρίς App Store. Τα δεδομένα μένουν κοινά με τον υπολογιστή, γιατί βρίσκονται στον server.

1. Ανοίξτε στο **Safari** τη διεύθυνση της εφαρμογής (π.χ. `https://kostologisi.example.gr`).
2. Πατήστε **Κοινοποίηση** (το τετράγωνο με το βέλος) → **Προσθήκη στην αρχική οθόνη** → **Προσθήκη**.
3. Ανοίξτε την «Κοστολόγηση» από το εικονίδιο και συνδεθείτε μία φορά. Η εγκατεστημένη εφαρμογή κρατά δική της σύνδεση, ξεχωριστή από το Safari.

Τι είναι προσαρμοσμένο για iPhone:

- Εικονίδιο, οθόνη εκκίνησης για iPhone/iPad, πλήρης οθόνη με σωστά περιθώρια για notch / Dynamic Island και τη γραμμή κάτω.
- Φωτογράφιση τιμολογίων με την κάμερα, και πολλές σελίδες για το ίδιο τιμολόγιο.
- Τα PDF παραστατικών εμφανίζονται μέσα στην εφαρμογή με όλες τις σελίδες (το Safari μόνο του δείχνει μόνο την πρώτη).
- Οι εξαγωγές Excel/CSV, τα αντίγραφα ασφαλείας και τα παραστατικά αποθηκεύονται από το μενού **Κοινοποίηση** → «Αποθήκευση στα Αρχεία», Mail, AirDrop ή Εκτύπωση.
- Όταν ανοίγει το πληκτρολόγιο, οι κάτω μπάρες κρύβονται για να μένει χώρος. Τα αριθμητικά πεδία ανοίγουν αριθμητικό πληκτρολόγιο με κόμμα.
- Επειδή η εγκατεστημένη εφαρμογή δεν έχει κουμπί ανανέωσης του Safari, υπάρχει κουμπί ↻ στην πάνω μπάρα. Τα δεδομένα ανανεώνονται επίσης μόνα τους κάθε φορά που επιστρέφετε στην εφαρμογή.
- Αν ο server δεν απαντά, η εφαρμογή ανοίγει κανονικά και δείχνει «Δεν υπάρχει σύνδεση» με κουμπί «Δοκιμή ξανά», αντί για λευκή σελίδα.

**Χρειάζεται HTTPS.** Χωρίς `https://` η εφαρμογή λειτουργεί στο iPhone, αλλά δεν έχει το μενού «Κοινοποίηση» για αρχεία ούτε άνοιγμα όταν ο server δεν απαντά. Τρόποι:

- **Server/VPS με δικό σας domain:** Caddy μπροστά από την εφαρμογή. Βγάζει αυτόματα πιστοποιητικό (βλ. ενότητα Α). Ορίστε `COOKIE_SECURE=1`.
- **Υπολογιστής στο μαγαζί:** μια υπηρεσία σήραγγας, όπως το Tailscale (`tailscale serve`, πρόσβαση μόνο από τις δικές σας συσκευές) ή το Cloudflare Tunnel. Δίνουν διεύθυνση `https://` χωρίς ρυθμίσεις στο router.

Αν το κουμπί «Εκτύπωση» δεν ανταποκρίνεται στην εγκατεστημένη εφαρμογή (εξαρτάται από την έκδοση iOS), εξάγετε σε Excel και επιλέξτε **Κοινοποίηση → Εκτύπωση**, ή ανοίξτε την ίδια σελίδα στο Safari.

### Ρυθμίσεις (μεταβλητές περιβάλλοντος)

| Μεταβλητή | Προεπιλογή | Περιγραφή |
|---|---|---|
| `PORT` | `3000` | Θύρα |
| `DATA_DIR` | `./data` | Φάκελος δεδομένων (βάση, παραστατικά, αντίγραφα) |
| `ANTHROPIC_API_KEY` | — | Κλειδί [Claude API](https://console.anthropic.com/) για αυτόματη ανάγνωση. Χωρίς αυτό όλα λειτουργούν, αλλά οι γραμμές συμπληρώνονται χειροκίνητα. |
| `AI_MODEL` | `claude-opus-5-5` | Μοντέλο ανάγνωσης |
| `AI_EFFORT` | `high` | Βάθος ανάλυσης (`low`, `medium`, `high`) — χαμηλότερο = φθηνότερο/γρηγορότερο |
| `BACKUP_INTERVAL_HOURS` | `24` | Συχνότητα αυτόματων αντιγράφων |
| `BACKUP_KEEP` | `14` | Πόσα αυτόματα αντίγραφα κρατούνται |
| `MAX_UPLOAD_MB` | `20` | Μέγιστο μέγεθος αρχείου |
| `COOKIE_SECURE` | `auto` | `1` όταν υπάρχει HTTPS |
| `SEED_SAMPLE` | `1` | `0` για εκκίνηση χωρίς παραδειγματικά δεδομένα |

**Σημείωση για την AI:** οι φωτογραφίες/PDF των παραστατικών στέλνονται στο Claude API της Anthropic μόνο για ανάγνωση. Η ανάγνωση γίνεται με «structured output» (αυστηρό σχήμα JSON) και ενεργό server-side fallback σε περίπτωση άρνησης του μοντέλου. Οι φωτογραφίες σμικρύνονται στο κινητό (μέγιστη πλευρά 2576 px) πριν σταλούν.

## Πρώτα βήματα

1. Η εφαρμογή ξεκινά με **παραδειγματικά δεδομένα** (σήμανση «ΠΑΡΑΔΕΙΓΜΑ»): υλικά, 4 τιμολόγια, συνταγές (μους, crumble, παντεσπάνι, κρέμα, gelato, ψωμί), προϊόντα (ποτηράκι μους, τούρτα, μερίδα gelato, ψωμί), στιγμιότυπο και πλάνο παραγωγής. Οι τιμές τους είναι πλασματικές.
2. Φωτογραφίστε ένα πραγματικό τιμολόγιο → ελέγξτε τις γραμμές → «Επιβεβαίωση τιμών».
3. Δημιουργήστε τις συνταγές και τα προϊόντα σας.
4. Όταν είστε έτοιμοι: Ρυθμίσεις → «Διαγραφή παραδειγματικών δεδομένων». Ό,τι παραδειγματικό χρησιμοποιείτε σε δικές σας συνταγές διατηρείται (χωρίς τις πλασματικές τιμές, άρα ως «Ελλιπές» μέχρι να μπει πραγματική τιμή).

## Κανόνες υπολογισμού

Όλοι οι υπολογισμοί γίνονται στον κώδικα (`shared/`), με τον ίδιο κώδικα σε server και browser, και ελέγχονται με αυτοματοποιημένα tests. Η AI μόνο διαβάζει έγγραφα και προτείνει αντιστοιχίσεις.

- **Συσκευασίες αγοράς:** συνολική ποσότητα = ποσότητα × (τεμάχια ανά συσκευασία × περιεχόμενο). Π.χ. 4 × 2,5 kg βούτυρο, καθαρή αξία 90 € → 10 kg → **9 €/kg**. Ένα κιβώτιο 4 × 2,5 kg δίνει το ίδιο αποτέλεσμα.
- **Καθαρή αξία:** χρησιμοποιείται η αναγραφόμενη. Αν λείπει, υπολογίζεται από ποσότητα × τιμή − εκπτώσεις και σημειώνεται. Αν διαφέρουν, εμφανίζεται προειδοποίηση. Γενική έκπτωση τιμολογίου κατανέμεται αναλογικά στις γραμμές.
- **ΦΠΑ:** αποθηκεύεται χωριστά. Η βάση κοστολόγησης (χωρίς ή με ΦΠΑ) είναι ρύθμιση και φαίνεται σε κάθε αποτέλεσμα.
- **Ενεργή τιμή:** η τελευταία επιβεβαιωμένη βάσει **ημερομηνίας παραστατικού**. Παλαιότερο τιμολόγιο που ανεβαίνει αργότερα μπαίνει μόνο στο ιστορικό. Μπορείτε να επιλέξετε χειροκίνητα άλλη τιμή του ιστορικού (📌).
- **Μετατροπές:** g↔kg και ml↔λίτρα αυτόματα. Βάρος↔όγκος μόνο με καταχωρισμένη πυκνότητα του υλικού· τεμάχια↔βάρος μόνο με βάρος τεμαχίου. Αλλιώς εμφανίζεται «Ελλιπές κοστολόγιο».
- **Απόδοση:** είτε πραγματική τελική απόδοση (υλικά 2.200 g → έτοιμο 2.000 g ⇒ κόστος/kg στα 2.000 g), είτε εκτιμώμενη φύρα %, είτε σύνολο υλικών. Ποτέ συνδυασμός, ώστε η ίδια απώλεια να μη μετριέται δύο φορές.
- **Επιμέρους συνταγές:** χρεώνεται το αναλογικό μερίδιο της παρτίδας τους (ποσότητα που χρησιμοποιείται ÷ απόδοση). Κάθε συνιστώσα μεταφέρεται ως έχει, άρα δεν υπάρχει διπλομέτρηση· αλλαγή σε βασική συνταγή ενημερώνει όλα τα προϊόντα.
- **Εργασία & λειτουργικά:** κάθε επίπεδο χρεώνει μόνο τη δική του εργασία/σταθερά έξοδα (ανά παρτίδα ή ανά Ν τεμάχια). Το ποσοστό λειτουργικών εφαρμόζεται μόνο σε κόστη που δεν έχουν ήδη επιβαρυνθεί με ποσοστό σε επιμέρους συνταγή.
- **Ελλείψεις:** υλικό χωρίς τιμή ή χωρίς δυνατή μετατροπή δεν θεωρείται ποτέ δωρεάν· το κοστολόγιο σημειώνεται «Ελλιπές» και το σύνολο εμφανίζεται ως μερικό. (Μηδενική τιμή επιτρέπεται μόνο ρητά, π.χ. για το νερό.)
- **Ακρίβεια:** πλήρης ακρίβεια στους ενδιάμεσους υπολογισμούς (και για 0,3 g αλάτι), στρογγυλοποίηση μόνο στην εμφάνιση.
- **Αριθμοί:** στα πεδία γράφετε `2,5` ή `2.5`· μόλις φύγετε από το πεδίο εμφανίζεται με κόμμα ώστε να φαίνεται πώς διαβάστηκε.

## Αντίγραφα ασφαλείας & επαναφορά

- Αυτόματο αντίγραφο κατά την εκκίνηση και κάθε 24 ώρες στο `DATA_DIR/backups` (κρατούνται τα 14 τελευταία).
- Ρυθμίσεις → «Λήψη πλήρους αντιγράφου»: ένα `.zip` με όλα τα δεδομένα, τις συνδέσεις και τα αρχικά παραστατικά. **Κατεβάζετε τακτικά ένα αντίγραφο και σε άλλη συσκευή.**
- Επαναφορά από αρχείο ή από λίστα αντιγράφων. Πριν από κάθε επαναφορά κρατείται αυτόματα αντίγραφο της τρέχουσας κατάστασης.
- Το ίδιο `.zip` χρησιμεύει για μεταφορά σε άλλον server.

## Για προγραμματιστές

```bash
npm run dev      # server (θύρα 3000) + Vite (http://localhost:5173)
npm test         # tests υπολογισμών και API (node:test)
npm run e2e      # δοκιμή στον browser σε κινητό, iPhone (προσομοίωση) & υπολογιστή (απαιτεί Playwright)
npm run ios-assets   # αναδημιουργία εικονιδίων/οθονών εκκίνησης iOS από το client/public/icon.svg
```

Δομή:

```
shared/      υπολογισμοί (μονάδες, τιμολόγια, κοστολόγηση, παραγωγή) — κοινοί για server και browser
server/      Express + SQLite (better-sqlite3), πρόσβαση, API, AI, αντίγραφα, εξαγωγές
client/      React (Vite), ελληνικό περιβάλλον, mobile-first
test/        tests μονάδων και API
scripts/     dev server, e2e
```
